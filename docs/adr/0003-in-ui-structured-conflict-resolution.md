# ADR-0003: 冲突解决在扩展 UI 内结构化进行，不引外部编辑器

冲突文件带 `<<<<<<<` 标记时，初版提示"edit then push"——用户必须去文件系统找文件手动编辑，观察与行动断裂。决定：在 Pi 扩展 UI 内做**结构化**解决——把冲突文本解析为独立冲突块，每块让用户选择"保留本地 / 保留远端 / 手动输入"，块级进度持久化到 state.json，全部解决后落盘并提示 push。`merge` 命令可续解，`--abort` 放弃并恢复备份。

**Considered Options**：TUI widget 内建整文件编辑器（自由但工程代价最大，ExtensionUIContext 无内建编辑器）；复用系统编辑器打开冲突文件（不是"同一界面"，且离开 TUI）；结构化块选择（选定——受控、每块有确定结局、纯函数可测）。

**Consequences**：解决的粒度是"块"不是"行"；同一文件内局部块可组合（本地+远端混用）；复杂自由编辑场景受限，可用"手动输入"块覆盖。
